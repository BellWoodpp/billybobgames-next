# BillyBobGames.org 冲击品牌词第一名行动清单

更新日期：2026-10-02

目标关键词：`billybobgames`

当前状态：`billybobgames.org` 排名约第 2；主要竞争站是 `billybobgames.com`。排名会因国家、设备和个性化发生变化，所以最终以 Google Search Console 的数据为准。

## 当前结论

现在最应该做的不是继续堆关键词，也不是增加首页字数，而是提高网站内容的真实性、品牌可信度和游戏库完整度。

公开检查发现：

- `billybobgames.org` Sitemap 当前约有 25 个 URL。
- `billybobgames.com` Sitemap 当前约有 201 个 URL。
- 两个网站的 Title、Description、Canonical、robots.txt 都基本正常。
- `.org` 已有 Organization、WebSite、WebPage 等结构化数据，基础技术 SEO 不是主要短板。
- `.org` 首页后半段存在较多与实际功能不完全一致的描述，例如 Windows 游戏下载、安装测试、搜索、编辑推荐、社区和评分等。
- `.com` 的游戏库更大，并且已有第三方网站把它作为 Billy Bob Games 的访问地址。

因此，优先级应该是：

1. 先修复首页内容真实性。
2. 再完善品牌身份与信任页面。
3. 再把核心游戏页做深、做完整。
4. 最后持续增加真实游戏内容和高质量外链。
